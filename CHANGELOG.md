# Changelog

This changelog records public-home releases separately from internal CLI development. It is not a substitute for the package's own release notes.

## 2026-10-21 — Stories, world and a new website

- *The Unfinished Chart* rewritten as **v3.0**: the same events, characters and dialogue, told in scenes instead of summary, with small added details (the answer to the two clocks in the prologue; what the three bells mean). Two continuity slips fixed (chalk on a whiteboard in Chapter II; Nell's exam date in Chapter III). The v2.0 text is archived unchanged in `lore/archive/unfinished-chart-v2.0/`.
- New short story, ***MØBIUS: Only One Side*** (v1.0): Mira's first winter at the station, and how it got its name. New canon is listed in `lore/canon.md`.
- The website is now six pages (home, character, stories, reader, world, agent) with an in-site reader, a reader's chart of Rovelle, and page moods drawn from the original art. Stories are built from `lore/catalog.json`.
- The original logo's outer paper removed for use on dark pages (`media/identity/mira-logo-cutout.png`); the logo itself is unchanged.
- New README and README images.
- Both stories and the character profile translated into English (`lore/en/`). On the English site the reader shows the translation; the Chinese text remains the original and the authority.
- The English site shows no Chinese beyond the language switch: quotes, titles and chapter names change with the language.
- Vard Light drawn as a sea chart's coastal view: seen from the supply ship on the home page, close up with the station on the world page. Its light turns every twelve seconds, as in the story.
- The home page keeps Mira's name and introduction clear of her face at every window size.
- Fixed: titles, covers and quotes revealed by a clip never appeared in Chrome.

## 2026-10-20 — Public home, initial edition

- Public-facing documentation and installation entry point for the published `mira-voss@1.0.0` npm release.
- Introduced the approved character key art and the original logo identity reference.
- Added a new Rovelle harbor splash illustration while retaining both original reference assets.
- Published the curated Rovelle canon and the original Chinese novella, *The Unfinished Chart*.
- Established clear boundaries between proprietary runtime code and public narrative materials.
- Published the static showcase through GitHub Pages and added issue and pull request templates.
