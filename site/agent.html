Mira, at work

Mira Voss is also a terminal agent you install from npm. Start her in a folder and she works there: she reads, edits, runs commands and shows you what she has done, within her configuration and the permissions you give her.

npm install -g mira-voss

Getting started

  1. Install

    Use Node.js 22 or newer, then run npm install -g mira-voss.

  2. Start her

    Open a terminal in the folder you want to work in and run mira. mobius works too.

  3. Sign in

    Follow the prompts. The npm page lists the current account and API-key options.

  4. Start small

    Give her a bounded task first. In the default mode, read each permission request before you accept it.

  5. If something fails

    Run mira doctor. Remove private paths and keys before you report a problem.

FAQ

Product and fiction

The story is not the spec

The stories give Mira a face and a voice. They do not describe the software. No line of fiction grants a permission, bypasses a review, guarantees a result, or tells you which model is running. What the CLI does is defined by its code, its model and provider, your configuration and the permissions you set.

Product vs. fiction
Is Mira open source?

No. The CLI runtime is proprietary. The public GitHub repository hosts documentation, the stories, her visual identity and this website, not the CLI's implementation.

How do I install or update her?

npm install -g mira-voss installs her, and npm install -g mira-voss@latest updates. If mira is not found afterwards, check that npm's global directory is on your PATH. See the installation guide.

Which platforms are supported?

The optional prebuilt kernel used for ChatGPT plan sign-in ships for macOS on Apple silicon in this release. The npm package page describes the other sign-in options and current platform details.

Why does a terminal agent have a backstory?

The character gives the product its visual and narrative identity. She is not a claim about the software's consciousness, autonomy, capabilities or security.

Is MØBIUS a city?

No. Rovelle is Mira's hometown. MØBIUS is the research station in the north where she works after the first book. Earlier drafts that used MØBIUS as a city are not canon.

Where do I report a problem?

Use the issue templates on GitHub. Include your OS, Node.js and Mira versions, and redact credentials and private paths. Security issues go through private vulnerability reporting.

May I reuse the art or the stories?

Not automatically. Public visibility does not grant permission to republish or commercially reuse them. See the notice.
