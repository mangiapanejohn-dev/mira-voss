# Static showcase

This directory contains the HTML/CSS website for the Mira Voss public home. It displays the new Rovelle splash illustration, original logo, npm installation command, and an introduction to the complete story. It contains no private runtime code. The page uses hosted fonts with local fallbacks.

To preview locally, run `python3 -m http.server 8080` from this directory and open `http://localhost:8080/`.

GitHub Pages deploys this directory through [the Pages workflow](../.github/workflows/pages.yml). The public address is [mangiapanejohn-dev.github.io/mira-voss](https://mangiapanejohn-dev.github.io/mira-voss/).
