# Contributing

This is a documentation, story, and community-facing repository. It does not contain the proprietary Mira Voss CLI runtime.

You are welcome to file issues for reproducible installation bugs, inaccuracies in documentation, broken links, accessibility problems, and user-experience suggestions. If pull requests are enabled, documentation typo fixes and accessibility improvements can be considered; acceptance remains at the maintainers' discretion.

Please do not submit or request unpublished runtime source code, proprietary credentials, or internal configuration. For lore feedback, distinguish factual continuity errors from suggestions for future stories. New characters, changes to established canon, and commissioned illustration work require explicit editorial approval.

By submitting material, you confirm that you have the right to submit it; submission does not change the copyright terms in [NOTICE.md](NOTICE.md).
