# Security policy

The Mira agent runtime is distributed separately through npm. This public repository does not contain the agent's private implementation.

Please **do not** post security vulnerabilities, API keys, session tokens, personal files, or exploitation details in public Issues.

If GitHub's **Private vulnerability reporting** feature is enabled for this repository, use it. Otherwise, ask the maintainer for a private reporting channel **without disclosing sensitive details publicly**.

Security properties of the CLI, supported environments, update channels, and handling procedures must be independently verified from the actual release; this repository does not make guarantees beyond the published product documentation.
