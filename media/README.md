## Visual rules

1. The original logo controls facial shape, side profile, bob haircut silhouette and black/white color blocking. Do **not** replace Mira with a generic character or a different face.
2. The key art establishes an approved *rendering direction*, not permission to change the identity.
3. Do **not** add halftone dots to new painterly pieces unless the asset is meant to reproduce the original logo.
4. Avoid generic AI motifs: floating circles, gratuitous glows, excess jewelry, meaningless technical glyphs, plasticky skin and over-rendered hair.
5. Aim for carefully art-directed, painterly, production-grade original illustration; learn from high-quality game key art without copying another franchise's characters or imagery.
6. Keep the original logo and earlier approved art in the repository as identity references when adding new illustrations.
