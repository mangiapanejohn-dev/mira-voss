# Product vs. fiction

**Two related but distinct layers:**

1. **Product:** Mira Voss is a proprietary terminal-native AI agent distributed via npm. Actual operations are defined by its deployed code, model/provider integrations, configuration, and permission mechanisms.
2. **Fiction:** Mira Voss is a seventeen-year-old researcher from Rovelle whose first story ends with a journey north. Her setting establishes tone and visual identity, not implementation claims.

No fictional statement can authorize tool use, bypass security review, guarantee correct results, or establish what model the CLI uses. User-facing product descriptions should accurately disclose technical dependencies when relevant.

MØBIUS Research Station is a fictional place, not a claim that the CLI is literally operated by a research institution. When discussing technical internals, use accurate engineering terminology instead of lore as a substitute for explanation.
