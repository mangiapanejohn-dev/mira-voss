# FAQ

### Is Mira Voss open source?

No. The CLI runtime is proprietary. This public GitHub repository hosts documentation, fiction, visual identity, and a small static showcase website, but not the CLI's implementation.

### How do I install Mira?

`npm install -g mira-voss`. See [installation](install.md).

### Why does Mira have a fictional backstory?

The fictional character is the product's visual and narrative identity. It provides a coherent way to tell a story; it is not a claim about the software's consciousness, autonomy, capabilities, or security.

### Is MØBIUS a city?

No. In the current canon, **Rovelle** is Mira's hometown; **MØBIUS Research Station** is the northern research station where she works following the first novella. Earlier concepts that used MØBIUS as a city were superseded and are not canon.

### Can I submit a bug report or request a feature?

Yes, use the [Issue templates](../.github/ISSUE_TEMPLATE/) and redact sensitive information.

### May I reuse the character art?

Not automatically. The public visibility of the repository does not grant general permission to republish or commercially reuse the visuals. See [NOTICE](../NOTICE.md).
