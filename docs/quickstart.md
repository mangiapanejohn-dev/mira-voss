# First launch

1. Use Node.js 22 or newer and [install Mira Voss](install.md): `npm install -g mira-voss`.
2. Open a terminal in the directory where you want Mira to work and run `mira` (or `mobius`).
3. Follow the sign-in prompts. The [npm package documentation](https://www.npmjs.com/package/mira-voss) describes the current account and API-key options.
4. Start with a bounded task. In the default mode, review Mira's permission requests before changes.
5. Run `mira doctor` if setup or a turn fails; redact private paths and credentials before [reporting a problem](https://github.com/mangiapanejohn-dev/mira-voss/issues/new/choose).

See the [installation guide](install.md) and [FAQ](faq.md). The proprietary runtime is distributed through npm, not this repository.
